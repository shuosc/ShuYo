# ShuYo 离线演示

首次启动时，在欢迎页轻点「体验演示模式」即可进入首页。校园账户登录页也支持已有的审核演示账号。

- **首页**可以查询校园卡余额与消费记录，打开图书馆演示座位、选择时段并预约，也可以在预约记录中取消。
- **课评**可以从课表进入课程、搜索课程与教师，并体验评价流程。演示评价只保留在当前会话。
- **学业**展示学分、绩点和排名。**日程**使用 2026 年秋季学期样本，可以翻周、编辑课程并恢复示例课表。
- **空教室**使用 2026 年 9 月 1 日 GA 楼的快照，支持切换节次与查看教室。通知公告提供四条带有详情的本地样本。

重新打开应用会继续使用演示模式。要结束体验，请在首页打开设置，轻点「退出演示」并确认。预约和评价均使用本地演示记录。
